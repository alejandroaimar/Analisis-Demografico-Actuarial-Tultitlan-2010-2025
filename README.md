# 📊 Análisis Demográfico y Actuarial del Municipio de Tultitlán, Estado de México (2010-2025)

> Proyecto completo de la asignatura **Demografía** | **Facultad de Ciencias, UNAM**

---

## 📌 Descripción General

Este repositorio contiene el **análisis demográfico completo** del municipio de **Tultitlán**, Estado de México, utilizando datos de los Censos de Población y Vivienda 2010 y 2020 del **INEGI**.

El proyecto integra **cuatro laboratorios** que cubren desde la estructura poblacional básica hasta indicadores avanzados de fecundidad, migración, mortalidad y tablas de vida, con un **enfoque actuarial** aplicado a seguros de salud, pensiones y educación.

---

## 🗂️ Estructura del Proyecto

| # | Laboratorio | Tema Principal | ¿Qué incluye? |
|:-|:---|:---|:---|
| **1** | Estructura Poblacional | Pirámides, calidad de datos, corrección 1/16 | Índices Whipple, Myers, UN; IM, ID; enfoque actuarial en salud |
| **2** | Crecimiento Poblacional | Tasas de crecimiento, proyecciones | Modelos geométrico/exponencial; tiempos de duplicación; proyecciones 2010-2025 |
| **3** | Mortalidad y Tablas de Vida | Tasas de mortalidad, esperanza de vida | TBM, TEM, TTM, TMI; tablas de vida; intervalo C50; pensiones |
| **4** | Fecundidad y Migración | Natalidad, migración, proyección de nacimientos | TBN, TFG, TEF, TGF, TBR, TNR; SNM, TI, TE, TNM; enfoque actuarial |

## 🛠️ Herramientas y Habilidades Demostradas

| Área | Habilidades | Ejemplo en el proyecto |
| :--- | :--- | :--- |
| **📊 Análisis de Datos** | Procesamiento de microdatos censales, corrección de datos, depuración | Método 1/16, índices Whipple y Myers |
| **📈 Modelado Matemático** | Proyecciones, modelos discretos y continuos, interpolación | Modelos geométrico/exponencial, intervalo C50 |
| **📉 Estadística Demográfica** | Tasas, indicadores, tablas de vida, relaciones de sobrevivencia | Cálculo de TBM, TEM, TTM, TMI, TEF, TGF, TBR, TNR |
| **💻 Excel Avanzado** | Fórmulas matriciales, funciones anidadas, gráficas, tablas dinámicas | Todo el proyecto está desarrollado en Excel |
| **📋 Análisis Actuarial** | Primas, reservas, siniestralidad, pensiones, seguros de salud | Implicaciones para seguros materno-infantiles, pensiones, educación |
| **📝 Comunicación Técnica** | Reportes estructurados, interpretación de resultados, gráficas | 4 informes PDF completos con tablas y conclusiones |

## 🔍 ¿Qué problema resuelve este proyecto?

Este proyecto demuestra cómo los **datos demográficos** pueden traducirse en **decisiones concretas** para:

| Sector | Pregunta que responde el proyecto |
| :--- | :--- |
| **🏥 Seguros de Salud** | ¿Cuántos nacimientos habrá en los próximos 5 años y cómo afecta la siniestralidad? |
| **🏦 Pensiones** | ¿Cómo afecta la emigración de jóvenes a la base de cotizantes? |
| **🏫 Educación** | ¿Cuántas escuelas se necesitarán en los próximos 10 años? |
| **🏛️ Gobierno** | ¿Tultitlán atrae o expulsa población? ¿Qué políticas se necesitan? |
